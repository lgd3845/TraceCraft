# TraceCraft 造物工坊

**TraceCraft 造物工坊** 是一款面向手作礼品设计与制作辅助的纯前端 Web 应用。用户无需绘画功底，上传一张照片或挑选内置示例，即可在浏览器本地离线生成 **拼豆、刺绣、绕线画、圆规画、雕刻画** 五类可实际动手落地的手作图纸与沉浸式分步教程。

所有图像处理、路径规划与图纸生成均在浏览器本地完成，照片不上传服务器；作品与制作进度保存在当前浏览器的 `localStorage` 中。

---

## 核心功能

### 五大手作工坊
1. **拼豆工坊（PERLER BEADS）**
   - 将照片采样量化为像素拼豆底稿，支持 16–64 格精度、8/16/24 色数、2.6 mm / 5 mm 豆径，提供「拼豆实感 / 像素图纸」切换及格内微调画笔（含擦除留空），自动统计材料色卡颗数。
2. **刺绣工坊（HAND EMBROIDERY）**
   - 匹配 DMC 真实色号，支持 **长短针**、**十字绣**、**戳戳绣** 三种针法及多种绣绷直径、绣布底色预设；内置连通区块分割与就近端点走线优化，提供实感效果、水消笔描图底稿与逐针跟绣引导。
3. **绕线画工坊（STRING ART）**
   - 在 Web Worker 中异步求解经典单色或三色混绕走线，支持外圈固定钉盘与自由轮廓布钉两种排布方式，提供成品全览、针号顺序表与逐步绕线定位。
4. **圆规画工坊（COMPASS HALFTONE）**
   - 支持 **同心圆分段弧**、**一笔阿基米德螺线**、**三圆心叠交网格** 三种画法，将图像明暗转化为半径、起止角度与控笔轻重指令，配合分色画笔色层与量角定位模板。
5. **雕刻画工坊（PAPER CARVING）**
   - 支持 **阳刻连桥刻纸**（自动检测悬空孤岛并生成防掉连接桥）、**阴刻版画木刻**、**多层光影纸雕**（4 层立体叠影），提供先内后外下刀顺序与第一象限正坐标参考网格。

### 统一交互与图纸导出
- **一屏专注工作台**：桌面端免滚动单屏布局，提供照片取景框选与内置精选示例，随时无门槛试手。
- **全屏沉浸式跟做**：五个工坊均支持全屏浏览，并在 4 个分步教程工坊的全屏视图下提供底影开关与无遮挡侧边步进控制器。
- **统一「导出图纸」弹窗**：支持按需勾选导出以下文件（可单选或多选批量下载）：
  - **高清图纸 PNG**：包含成品预览、网格/针法/步骤速查、材料色卡与安全提示的完整制作图。
  - **1:1 原寸底稿 SVG**：含 `50 mm` 比例尺、对位标记（绣绷 12 点位 / 起线钉 / 圆心 / 刻纸第一象限刻度），适合按 100% 实际大小打印。
  - **材料与步骤清单 CSV**：转义防公式注入，可用 Excel/WPS 打开核对色号、线长与逐步操作参数。
- **本地作品库**：支持弹窗命名保存/更新作品，随时回溯编辑或导出。

## 技术栈

- **前端框架**：React 19 + TypeScript（`strict` 模式）+ Vite 7
- **图形与导出**：原生 HTML5 Canvas 2D、矢量 SVG 生成、Blob/CSV 本地导出
- **后台计算**：Web Worker 异步绕线优化计算（`src/modules/wire-craft/stringArt.worker.ts`）
- **图标与样式**：`lucide-react` + 模块化 CSS
- **测试体系**：Vitest 单元测试（算法、存储、Canvas/SVG/CSV 契约） + Playwright 浏览器端到端测试（桌面端 `1440×1000` 与移动端 `390×844`）

## 本地开发与测试

环境要求：**Node.js >= 22.12.0**（仓库根目录 `.nvmrc` 为 `24`）。

```bash
# 安装依赖
npm install

# 启动本地开发服务器
npm run dev

# 运行单元测试（Vitest）
npm test

# 类型检查并构建生产产物
npm run build

# 运行端到端浏览器测试（需先确保开发服务器或环境可用 Chromium）
npm run test:e2e
```
